# Convox launch video

A Remotion project. The call audio is real Convox output, generated by
`tools/launch_audio.py` (Sarvam Mayura translation, Bulbul voices, the number check):

    uv run python tools/launch_audio.py        # from the repo root; needs SARVAM_API_KEY
    cd launch-video && npm install
    npm run studio                             # preview and edit
    npm run render                             # out/convox-launch.mp4 (1920×1080)
    npm run render:vertical                    # out/convox-launch-vertical.mp4 (1080×1920)

Scenes (src/Launch.tsx): who they are, the call without Convox, Convox joins, the same
call with it, the end card. Timings come from src/timeline.ts, built on the real
per-line translation and voice delays in src/call.json.
